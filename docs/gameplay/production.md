La producción requiere un edificio propio completo, recursos y población disponible. Las colas de unidades admiten **5 trabajos**; la investigación del Research Facility admite **3**.

| Edificio | Producción |
| --- | --- |
| COMMAND | MULE |
| Vehicle Foundry | KESTREL / Scout, Bastion, Missile Tank, EMP Carrier |
| Aircraft Hangar | Fighter Jet, Bomber |
| Combot Assembly | Combots a partir de piezas disponibles |
| Combot Part Factory | Piezas de tecnologías conocidas |
| Orbital Platform | Orbital Gunship |

EMP Carrier requiere un Research Facility propio completo.

Selecciona un productor y usa clic derecho para configurar su rally. Un rally de recursos guía a los MULEs hacia un depósito.

Las unidades salen por la puerta: si la salida está bloqueada, esperan a que se despeje. Cancelar un trabajo de producción devuelve su coste y libera la población reservada.
