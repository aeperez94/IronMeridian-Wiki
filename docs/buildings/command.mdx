## Descripción

Produce MULEs y recibe Ferrite. Debes mantener al menos un COMMAND completo para evitar la derrota.

## Uso en partida

Producción de MULEs y núcleo de base. Consulta [Construcción](/docs/gameplay/construction).

## Requisitos

MULE, recursos suficientes y colocación válida en una capa compatible.
