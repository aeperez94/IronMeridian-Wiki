Los atajos se pueden reasignar en Settings. Estas son las teclas por defecto; el contexto del panel activo puede cambiar la acción.

| Entrada | Acción | Contexto |
| --- | --- | --- |
| Clic izquierdo / arrastrar | Seleccionar / selección de área | Campo de batalla |
| Shift + clic | Añadir o quitar selección | Selección |
| Doble clic | Seleccionar aliados visibles del mismo tipo | Capa actual |
| Clic derecho | Orden contextual: mover, atacar, recolectar o usar acceso propio | Selección |
| A + clic | Ataque dirigido sobre enemigo; Attack Move sobre terreno | Órdenes |
| X | Stop | Selección |
| Shift + orden | Añadir Move, Attack, Attack Move o Build a la cola | Órdenes |
| G | GATHER Ferrite | MULE |
| C | Recoger wrecks cercanos | MULE |
| B | Abrir catálogo de construcción | MULE |
| Tab | Rotar edificio | Colocación |
| T | Usar acceso propio más cercano | Selección |
| O | Transferencia Orbit / Surface | Selección compatible |
| R | Orbital Strike | Acción orbital |
| F | Self-destruct EMP | EMP Carrier |
| I | Seleccionar MULEs inactivos | Global |
| F1 / F2 / F3 | Ver Orbit / Surface / Underground | Global |
| Space / Home | Centrar selección / COMMAND | Cámara |
| WASD | Desplazar cámara | Cámara |
| Q / E | Rotar cámara | Cámara |
| Rueda | Zoom | Cámara |
| Botón central + arrastrar | Desplazar cámara | Cámara |
| Ctrl + 1–9 / 1–9 | Asignar / seleccionar grupo | Global |
| Esc | Cerrar modo activo o abrir menú | Contextual |

## Construcción

Con el catálogo de construcción abierto: **K** COMMAND, **F** Vehicle Foundry, **G** Flux Generator, **C** Combot Assembly, **P** Combot Part Factory, **R** Research Facility, **V** Scout Tower, **J** Stratum Elevator, **U** Orbital Uplink, **N** Solar Array y **H** Orbital Bastion.

El atajo de construcción de Aircraft Hangar queda **TBD**. Usa su botón en el catálogo.

## Multijugador

El menú local permite Options y RESIGN. Abrirlo no pausa la partida para el rival.
